# Changelog

All notable changes to WealthTracker are documented here.

## Unreleased

### Added

- C++23 named-module architecture.
- Qt Quick desktop interface with Russian localization-ready strings.
- SQLCipher storage and operating-system credential integration.
- Local statement imports for common Russian-bank export formats.
- Read-only T-Invest and Bank of Russia FX clients.
- Official read-only Alfa-Bank B2C, T-Bank Business, and Modulbank clients.
- Paginated bank synchronization with tokens stored in the system credential
  store and normalized account, balance, transaction, and category views.
- Personal-finance and portfolio analytics.
